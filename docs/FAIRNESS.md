# Fairness evaluation status

**Status: not evaluated.**

The FER-2013 and FER+ files available in this workspace do not provide reliable skin-tone, gender, or age annotations for the images. No demographic traits are inferred from pixels, and aggregate performance must not be presented as evidence that the system is fair.

A future audit needs a separately licensed dataset or consented, human-reviewed evaluation set with clearly defined annotation protocol, adequate sample counts, and privacy protections. It should report per-group precision, recall, macro-F1, calibration error, conformal coverage, confidence intervals, and intersectional limitations. Group labels must not be guessed by this model.
